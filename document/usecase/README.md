# Use Case - Hệ thống quản lý chuỗi cửa hàng Coffee

Các sơ đồ được viết bằng PlantUML và chia theo phân hệ để dễ đọc, chỉnh sửa và đưa vào tài liệu phân tích thiết kế.

## Danh sách sơ đồ

1. `00-use-case-tong-quan.puml` — phạm vi toàn hệ thống.
2. `01-tai-khoan-phan-quyen.puml` — đăng nhập, tài khoản và phân quyền.
3. `02-chi-nhanh-nhan-su.puml` — chi nhánh, nhân viên, lịch làm và ca bán hàng.
4. `03-san-pham-kho.puml` — menu, công thức, nguyên liệu và nhà cung cấp.
5. `04-ban-hang-don-hang.puml` — ứng dụng bán hàng, pha chế, thanh toán tiền mặt và giao hàng.
6. `05-khach-hang-khuyen-mai.puml` — ứng dụng khách hàng, thành viên và khuyến mãi.
7. `06-bao-cao-kiem-soat.puml` — báo cáo, dự báo và nhật ký kiểm soát.

Có thể mở từng file bằng extension PlantUML của VS Code hoặc chạy PlantUML để xuất PNG/SVG.
